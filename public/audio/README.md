# The Hanging Tree

Agregar aquí el archivo de audio proporcionado por la usuaria, con el nombre `the-hanging-tree.mp3`.
No está incluido en el proyecto. Si el archivo está en M4A/OGG, se debe actualizar `BURN_AUDIO_SRC` en `lib/burn.js` para usar su nombre real sin cambiarle solo la extensión.

La secuencia usa audio nativo sin controles visuales, respeta el silencio global y libera el sonido al salir. No descarga, extrae ni incrusta YouTube.
